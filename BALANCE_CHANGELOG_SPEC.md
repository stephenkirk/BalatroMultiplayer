# Balance Changelog Spec

Each entry is a single bullet under a `## [version] - date` heading.

```
- **<Item>** (<Type>/<Ruleset>) <Change Type> — <what changed>: <one-sentence rationale>
```

**Example:**
```
- **Golden Ticket** (Joker/Sandbox) Nerf — Cost `5` → `4`: cheaper to compensate for 1-in-2 EV vs. guaranteed vanilla Ticket ($3).
```

**Change types:** Buff · Nerf · Rework · New · Removed · Fix

To add an entry automatically, run `/balance-entry` in Claude Code.
